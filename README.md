# 포스트잇 메모장

크롬 브라우저 오른쪽에 고정되는 포스트잇 스타일 메모장 확장 프로그램입니다. `chrome.sidePanel` API를 사용해 툴바 아이콘을 클릭하면 브라우저 오른쪽 끝에 패널로 열립니다.

## 주요 기능

- **오늘의 정보**: 헤더에서 사자성어, 명언, 날짜, 코스피 중 선택. 사자성어는 날마다 바뀌며, 마우스를 올리거나 포커스하면 한글음과 뜻을 표시하고 클릭하면 네이버 한자사전 검색 결과가 새 탭으로 열림
- **메모 추가**: `+ 새 메모` 버튼으로 새 포스트잇 생성 (최신 메모가 목록 맨 위에 표시)
- **제목 / 내용 입력**: 메모마다 제목과 본문을 자유롭게 편집, 본문은 입력에 따라 자동으로 높이 조절
- **URL 자동 링크**: 본문의 HTTP·HTTPS 주소를 메모를 불러오거나 편집을 마칠 때 클릭 가능한 링크로 표시. 클릭하면 새 탭으로 열리며 글자 서식은 유지됨
- **글씨체 설정**: 헤더의 테마 버튼 왼쪽 `가` 버튼을 누르면 굵게/기울임/밑줄과 글자색(기본 6색 + 직접 고르기 + 지우기)을 고를 수 있는 팝오버가 열림. 선택 없이 캐럿만 있는 상태에서 걸어도 그 뒤에 입력하는 글자에 그대로 적용됨. `가` 버튼 자체가 지금 캐럿의 서식(굵기·기울임·밑줄·색)을 실시간으로 보여 줘서 팝오버를 안 열어도 현재 상태를 알 수 있음. `Ctrl+B`/`Ctrl+I`/`Ctrl+U`(맥은 `⌘`) 단축키로도 굵게/기울임/밑줄을 걸고 뗄 수 있음
- **메모별 시간 알림**: 각 메모 하단의 종 버튼에서 알림 시각, 정각·5분 전, 반복, 소리(기본 켜짐)를 설정하거나 알림을 지울 수 있음. 알림은 브라우저 알림으로 표시되어 직접 닫을 때까지 남고, 소리는 확장이 직접 재생함. 반복 없이 설정하면 한 번만 울리며, 브라우저를 꺼 둔 사이 놓친 알림은 다음 시작 때 한 번 표시함
- **반복 알림**: 매일은 처음 설정한 같은 시각, 매주는 같은 요일·시각, 매월은 같은 날짜·시각에 반복. 해당 날짜가 없는 달은 마지막 날에 울리고 다음 달에는 원래 날짜로 돌아옴. 정각·5분 전 옵션은 반복 알림에도 적용되며, 놓친 반복 알림은 한 번 표시한 뒤 다음 예정 시각으로 넘어감
- **알림 설정창 위치 조절**: 위쪽 공간이 부족하면 아래로 열려 첫 번째 메모에서도 헤더에 가리지 않음. 공간이 좁으면 설정창 내부를 스크롤할 수 있음
- **메모 색깔 변경**: 메모 하단의 색상 스와치에서 6가지 기본 색상(노랑/주황/분홍/초록/파랑/보라) 중 선택하거나, 맨 오른쪽 무지개 칸을 눌러 원하는 배경색을 직접 지정
- **테마**: 헤더의 테마 버튼으로 시스템 설정 / 라이트 / 다크 순환. 다크모드에서는 포스트잇 색이 눈에 편한 짝으로 자동 변환됨
- **좁은 폭 지원**: 하단은 한 줄로 유지하고 알림시간은 전체 표시. 공간이 부족하면 메모 시간 표시를 왼쪽 연도부터 `....`으로 점차 축약하며, 전체 시간은 마우스를 올리면 확인 가능. 더 좁아지면 색상 스와치 영역을 가로로 스크롤할 수 있음
- **드래그 앤 드롭 정렬**: 메모 헤더의 `⠿` 핸들을 끌어서 순서 변경
- **삭제**: 메모별 삭제 버튼 (확인 후 삭제)
- **자동 저장**: `chrome.storage.local`에 저장되어 브라우저를 껐다 켜도 유지
- **맞춤법 밑줄은 편집 중에만 표시**: 제목/본문에 포커스가 있을 때만 맞춤법 검사가 동작하고, 포커스가 빠지면(보기 모드) 빨간 밑줄이 사라짐

## 설치 방법

1. 크롬 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 후 이 저장소 폴더 선택
4. 툴바의 확장 아이콘 클릭 → 브라우저 오른쪽에 사이드패널로 메모장이 열림

> 사이드패널 기능은 Chrome 114 이상에서 지원됩니다.

## 최신 버전: 1.0.13

- HTTP·HTTPS URL 자동 링크 추가
- 매일·매주·매월 반복 알림과 정각·5분 전 선택 추가
- 알림 설정창의 위·아래 위치 자동 조절
- 좁은 패널에서 알림시간을 유지하고 메모 시간을 왼쪽부터 축약

기존 설치는 저장소를 업데이트한 뒤 `chrome://extensions`에서 확장 프로그램을 새로고침하면 적용됩니다.

## 사용하는 권한

| 권한 | 용도 |
| --- | --- |
| `storage` | 메모와 설정을 브라우저에 저장 |
| `sidePanel` | 툴바 아이콘을 눌렀을 때 오른쪽 사이드패널로 열기 |
| `alarms` | 메모별 알림 시각에 맞춰 깨어나기(서비스 워커가 꺼져 있어도 동작) |
| `notifications` | 알림 시각에 브라우저 알림 표시 |
| `offscreen` | 알림음 재생(서비스 워커는 소리를 낼 수 없어 보이지 않는 문서를 잠깐 띄움) |

> 1.0.9에서 `alarms`, `notifications`, `offscreen` 권한이 추가되었습니다. 이미 설치해 둔 경우 `chrome://extensions`에서 확장 프로그램을 새로고침하세요. 알림 소리는 Chrome 109 이상에서 재생됩니다.

## 파일 구성

```
memo_extension/
├── manifest.json     # 확장 프로그램 설정 (Manifest V3)
├── background.js     # 툴바 클릭 시 사이드패널 열기, 메모 알림(alarms/notifications) 처리
├── offscreen.html/js # 알림 시각에 알림음을 재생하는 보이지 않는 문서(서비스 워커는 소리를 못 냄)
├── sounds/chime.wav  # 알림음
├── sidepanel.html     # 메모장 UI 구조
├── sidepanel.css     # 포스트잇 스타일
├── sidepanel.js      # 메모 CRUD, 서식/색상 변경, 드래그 정렬 로직
├── idioms.js         # 헤더에 표시할 사자성어 목록(한자·음·뜻)
├── quotes.js         # 헤더에 표시할 명언 목록
└── icons/            # 툴바/확장 아이콘
```
