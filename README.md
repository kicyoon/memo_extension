# 포스트잇 메모장

크롬 브라우저 오른쪽에 고정되는 포스트잇 스타일 메모장 확장 프로그램입니다. `chrome.sidePanel` API를 사용해 툴바 아이콘을 클릭하면 브라우저 오른쪽 끝에 패널로 열립니다.

## 주요 기능

- **메모 추가**: `+ 새 메모` 버튼으로 새 포스트잇 생성 (최신 메모가 목록 맨 위에 표시)
- **제목 / 내용 입력**: 메모마다 제목과 본문을 자유롭게 편집, 본문은 입력에 따라 자동으로 높이 조절
- **색깔 변경**: 6가지 포스트잇 색상(노랑/주황/분홍/초록/파랑/보라) 중 선택
- **드래그 앤 드롭 정렬**: 메모 헤더의 `⠿` 핸들을 끌어서 순서 변경
- **삭제**: 메모별 삭제 버튼 (확인 후 삭제)
- **자동 저장**: `chrome.storage.local`에 저장되어 브라우저를 껐다 켜도 유지

## 설치 방법

1. 크롬 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 후 이 저장소 폴더 선택
4. 툴바의 확장 아이콘 클릭 → 브라우저 오른쪽에 사이드패널로 메모장이 열림

> 사이드패널 기능은 Chrome 114 이상에서 지원됩니다.

## 파일 구성

```
memo_extension/
├── manifest.json     # 확장 프로그램 설정 (Manifest V3)
├── background.js     # 툴바 클릭 시 사이드패널 열기
├── sidepanel.html     # 메모장 UI 구조
├── sidepanel.css     # 포스트잇 스타일
├── sidepanel.js      # 메모 CRUD, 색상 변경, 드래그 정렬 로직
└── icons/            # 툴바/확장 아이콘
```
